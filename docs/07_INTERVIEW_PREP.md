# CampusHire — Interview Preparation Map

The project is intentionally designed to generate Java FSE interview discussion.

## Core Java
Be prepared to explain:
- OOP pillars
- encapsulation
- abstraction
- inheritance
- polymorphism
- constructors
- interfaces
- abstract classes
- access modifiers
- static/final
- equals/hashCode
- String immutability
- exception hierarchy
- checked vs unchecked exceptions
- custom exceptions
- Collections
- List vs Set vs Map
- ArrayList vs LinkedList
- HashMap basics
- Java Streams
- lambda expressions

## JDBC
Explain:
- Driver/connection
- PreparedStatement
- ResultSet
- transactions
- why PreparedStatement is preferred
- connection closing/resource management

## SQL
Be prepared for:
- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- ORDER BY
- aggregate functions
- primary/foreign keys
- normalization
- indexes

## REST
Explain:
- GET/POST/PUT/DELETE
- status codes
- JSON
- request/response
- REST-style resource design

## React
Explain:
- components
- props
- state
- useState
- useEffect
- React Router
- API calls
- controlled forms
- conditional rendering
- reusable components

## Project-Specific Questions
1. Why did you choose CampusHire?
2. Explain the architecture.
3. Why DAO and Service layers?
4. How does eligibility checking work?
5. How do you prevent duplicate applications?
6. How does React communicate with Java?
7. How does JDBC connect to MySQL?
8. What happens when a student clicks Apply?
9. How are application status transitions handled?
10. How are dashboard statistics calculated?
11. What validation occurs on frontend vs backend?
12. What would you improve if you had more time?
